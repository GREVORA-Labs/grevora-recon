# Security policy

Do not publish sensitive details or working exploit steps in public issues. Contact maintainers privately through the contact method on the GREVORA-Labs GitHub organization profile.

GREVORA Recon is for authorized, low-impact HTTP posture checks only. The scope file is a safety control, not proof of authorization. DNS can change between checks and requests; this simple guard is not a substitute for written permission, an approved asset inventory, or network egress controls.
